#  VoiceForge

VoiceForge is a simple and user-friendly AI-powered Text-to-Speech (TTS) web application that converts text into natural-sounding speech and allows users to download the generated audio as an MP3 file.

##  Features

* 🔤 Convert text into speech
* 🌍 Multiple language support
* 🎧 Natural AI-generated voices
* 📥 Download audio as MP3
* ⚡ Fast and responsive interface
* 📱 Works on desktop and mobile browsers

##  Built With

* React
* Vite
* Tailwind CSS
* JavaScript
* AI Text-to-Speech API

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mallikarjun-aihub/voiceforge.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
